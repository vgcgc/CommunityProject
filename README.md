# 📖 Community Project

<br/>
게시글 작성 및 댓글 작성 서비스

---
__회원 서비스__
1. 로그인
   정상적인 로그인시 JWT 토큰 발급
    - 게시글 검색 제외 로그인 후 접근할 수 있음
2. 로그아웃
3. 회원가입
    - ID는 중복으로 만들 수 없도록 중복 체크
4. 회원탈퇴

---
__게시글 서비스__
1. 게시글 검색
2. 게시글 작성
    - 게시글의 제목은 필수 입력값임
3. 게시글 편집
4. 게시글 삭제

---
__댓글 서비스__
1. 댓글 작성
2. 댓글 수정
3. 댓글 삭제
